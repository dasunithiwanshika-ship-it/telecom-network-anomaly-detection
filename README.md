# Telecom Network Anomaly Detection

## Project Overview

This project investigates machine learning approaches for detecting anomalies in telecom network KPI data using publicly available datasets.

## Objectives

- Learn telecom network concepts
- Analyze telecom KPI data
- Compare anomaly detection techniques
- Build an AI/ML prototype
- Develop software engineering and MLOps skills
